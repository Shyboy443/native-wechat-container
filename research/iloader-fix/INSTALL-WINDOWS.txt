FREE IPHONE SETUP WITHOUT SIDESTORE

This is an unofficial iLoader-based installer and matching LiveContainer prototype.
No paid Apple Developer membership is needed. A Windows computer, a normal Apple
Account, Apple USB drivers, and your own unlocked iPhone are required.
Apple Account sign-in and two-factor verification are done by you in the installer.

1. Connect your iPhone by USB, unlock it, and tap Trust if prompted.
2. Open AccountContainer-Installer.exe on Windows. Sign in to your Apple Account.
3. Select your iPhone, click Import IPA, and choose NativeContainer-unsigned.ipa.
   Do not choose SideStore or LiveContainer+SideStore. Keep extensions if prompted.
4. On the phone, follow Apple's developer-app trust and Developer Mode prompts.
   Open LiveContainer. The signing certificate should import automatically.
   Settings > JIT-Less Mode Diagnose > Test JIT-Less Mode must pass.
   On first launch, iOS asks whether to allow LiveContainer notifications. Allow
   them to avoid permission setup blocking apps such as WhatsApp. If previously
   denied, use LiveContainer Settings > Permissions > Open Notification Settings.
5. In Telegram on the phone, download WeChat from https://t.me/iosrxwy/14320
   and choose Share > Save to Files. In LiveContainer, tap + > Install IPA File
   and select that IPA. If the package was already copied to LiveContainer's
   Documents folder, tap Import WeChat on the Apps tab.
6. Test a spare WeChat account first. Then long-press WeChat > Settings >
   Add WeChat account profile. Choose a profile before launching and signing in.
   Test both accounts, close/reopen the app, and confirm each profile stays separate.

WHATSAPP AND OTHER APPS
Choose IPA File stays visible on the Apps tab. Import each compatible IPA separately.
Long-press an imported app > Settings > Add [app name] account profile to create
separate storage. Select the desired profile before launching. This does not guarantee
that every app supports login or multiple accounts inside LiveContainer.
If WhatsApp-candidate.ipa was separately copied into the host Documents folder,
tap Import WhatsApp. New WhatsApp imports enable Fix Local Notifications by default.
If setup gets stuck requesting notifications, long-press
WhatsApp > Settings > Fix Local Notifications, then try again. This compatibility
setting does not enable remote push notifications. Test with a spare account.
Never replace an official installed app or its existing data to add a container guest.
Camera, microphone, photos, and contacts prompt only when the imported app uses them.

RETURN TO THE APP LIST
Open the iPhone app switcher, swipe LiveContainer away, and open LiveContainer again.

INVITING OTHER TESTERS
There is no TestFlight invite or redeem code for this prototype. Share the unsigned
Windows setup package; each tester installs using their own Apple Account and USB.
App IPAs are separate dependencies. Never share a tester's signed host or certificate.

RENEWAL
Free signing normally lasts seven days. Before the displayed expiry, reconnect to
this computer and install the same NativeContainer-unsigned.ipa again using the
same Apple Account. Keep the existing app installed; do not delete it to renew.
Check both account sessions after renewal. A new certificate invalidates signatures
made with the old one, so avoid revoking certificates unless fixing a confirmed error.

STATUS
Compilation and synthetic certificate checks do not prove iPhone installation,
WeChat login, reopening, account separation or renewal. These require device tests.
The third-party WeChat IPA passed local archive/encryption checks, but its authenticity
and runtime compatibility have not been established. Notifications while locked are outside scope.
